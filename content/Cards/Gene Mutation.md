# Gene Mutation

> [!Ontology]+
> up:: [[Cards/Mutation]], [[Genes]]
> jump::
> down:: [[Cards/Silent Mutation]], [[Cards/Missense Mutation]], [[Cards/Frameshift Mutation]], [[Cards/Nonsense Mutation]]

- A [[Mutation]] that changes the bases in a [[Cards/Deoxyribonucleic Acid]] molecule.
- Change to the bases in a [[Cards/Codon]] can change the [[Cards/Amino Acids\|amino acid]] that it codes for.
- When a base is changed it has a follow-on effect as the bases must be complementary.

### Consequences

1. [[Silent Mutation]] - No Effect
2. [[Missense Mutation]] - New [[Cards/Amino Acids\|amino acid]]
3. [[Frameshift Mutation]] - addition or deletion of more [[Cards/Nucleotides]], forming new [[Cards/Amino Acids]] from that point on
4. [[Nonsense Mutation]] - causes the formation of the [[Cards/Stop Codon]]
